Business Analyst interview agent

Describe a project; the agent interviews you subject by subject, then produces an approved requirements summary, a Functional Specification Document and process diagrams.

  • Control flow is deterministic — the model only writes content, never decides what happens next.
  • Resumable — close the tab or restart the server; the interview continues where it stopped.
  • Local-first — every call goes to a model server on your machine (LM Studio or Strata).
